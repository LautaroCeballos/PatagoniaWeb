# AGENTS.md

Proyecto: **Diseño Web Patagonia** — Landing page para hoteles.

## Stack

- **Build tool:** Vite
- **CSS:** Plain CSS (no Tailwind, no framework)
- **JS:** Vanilla JS (ES modules)

## Proyecto

```
/index.html          → HTML
/src/main.js         → JS entry point
/src/style.css       → CSS completo
/package.json        → Vite como única dependencia dev
/vite.config.js      → Config Vite
```

## Comandos

- `npm run dev` — servidor local con HMR en `http://localhost:5173`
- `npm run build` — build a `dist/`
- `npm run preview` — preview del build
